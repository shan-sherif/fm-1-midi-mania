# Starter songs

Built into the firmware ahead of your own songs in `midi/` (`tools/gen_songs.py`), so every build, the browser
version included, has something to play. Only files whose source and licence are known and allow sharing go here:
a public-domain composition can still be someone's copyrighted MIDI arrangement. Your own MIDI files go in `midi/`,
which git ignores.
